# Claude Code Usage Instructions

This project is developed using Claude Code following a spec-driven approach with no manual coding.

## Project Philosophy

- All implementation originates from written specifications
- No manual coding is allowed - all changes must come through improved specifications
- Follow the workflow: Write Spec → Generate Plan → Break into Tasks → Implement via Claude Code
- Maintain clean code practices with modular design and clear naming

## Claude Code Workflow

1. **Specification Development**: Update specs in the `specs_history` folder with version numbering
2. **Implementation Generation**: Use Claude Code to generate code based on specifications
3. **Task Management**: Track progress using Claude Code's task tools
4. **Code Review**: Verify generated code matches specification requirements

## Project Structure

- `/src` - Python source code generated by Claude Code
- `/specs_history` - All specification versions (spec_vX.X_name.md)
- `README.md` - Setup and usage instructions
- `CLAUDE.md` - This file, Claude Code usage instructions
- `constitution.md` - Project constitution and requirements

## Specifications Process

1. Start with the initial specification in `specs_history/spec_v0.1_initial.md`
2. As requirements evolve, create new spec files with incremented version numbers
3. Use clear, descriptive names for spec files
4. Each new spec should reference the previous version and highlight changes

## Claude Code Commands

Use these Claude Code commands during development:

- `/tasks` - View current task list
- `TaskCreate` - Add new development tasks
- `TaskUpdate` - Update task status (pending, in_progress, completed)
- `TaskList` - List all tasks
- Use the Edit tool to modify files based on specifications
- Use the Write tool to create new files when needed

## Development Constraints

- No manual coding outside of Claude Code
- Only in-memory data storage (no databases or file persistence)
- Follow Python 3.13+ standards
- Maintain clean, modular code structure
- All implementation must trace back to specifications
