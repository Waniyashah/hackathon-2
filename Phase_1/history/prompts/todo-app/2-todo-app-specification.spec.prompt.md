## Prompt

Project: Evolution of Todo – Phase I In-Memory Python Console Application

Target:
Build a command-line Todo application that runs entirely in memory and demonstrates core task management functionality using spec-driven development. Implementation must be generated via Claude Code using Spec-Kit Plus following the agentic development workflow.

Primary Users:
Developers and evaluators interacting with a CLI-based task management system.

Core Scope:

The application must support the following Basic Level features:

1. Add Task:
   - Create new todo items.
   - Each task must include:
        - Unique ID
        - Title
        - Description
        - Completion status (default: incomplete)

2. View Task List:
   - Display all tasks in the console.
   - Show clear status indicators (complete/incomplete).

3. Update Task:
   - Modify existing task title and/or description using task ID.

4. Delete Task:
   - Remove task using task ID.

5. Mark as Complete:
   - Toggle task completion status between complete and incomplete.

System Behavior Requirements:

- Tasks stored only in memory during runtime.
- No persistent storage (no database, no file system).
- Console-based interaction with simple menu or command-driven flow.
- Clear and readable output formatting.
- Graceful handling of invalid input or missing task IDs.

Development Approach:

- Fully spec-driven implementation.
- Follow workflow:
    Write Specification → Generate Plan → Break into Tasks → Implement via Claude Code.
- No manual coding allowed.
- Spec refinement permitted until correct behavior achieved.

Technology Constraints:

- Python 3.13+
- UV environment
- Claude Code
- Spec-Kit Plus

Success Criteria:

- Running CLI application that demonstrates:
    - Adding tasks with title and description.
    - Listing tasks with visible completion status.
    - Updating existing tasks.
    - Deleting tasks by ID.
    - Marking tasks complete or incomplete.
- Generated code follows clean structure and modular design.
- Implementation traceable to specification.

Out of Scope (Not Building):

- No graphical user interface.
- No web application or APIs.
- No database or persistent storage.
- No advanced features (priority levels, filtering, reminders, AI chatbot).
- No cloud deployment or Kubernetes integration (reserved for later phases).

Deliverables:

- Source code generated by Claude Code.
- Spec history maintained for iterations.
- Proper Python project structure under /src.
